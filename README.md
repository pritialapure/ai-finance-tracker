# AI Finance Tracker

A full-stack personal finance management application that helps users track income and expenses, manage budgets, and gain insights into their financial activity.

## Live Demo

- **Frontend:** https://ai-finance-tracker-eosin.vercel.app
- **Backend API:** https://ai-finance-tracker-q05j.onrender.com

## Features

- User registration and authentication
- Secure JWT-based authentication
- Add and manage financial transactions
- Track income and expenses
- Budget management
- Financial insights and analytics
- Interactive data visualization
- Responsive user interface
- RESTful API integration
- Protected routes
- Centralized state management using Redux Toolkit
